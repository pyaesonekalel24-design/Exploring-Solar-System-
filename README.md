# Kal-El's Solar System Simulation

An interactive, browser-based solar system exploration simulator built with JavaScript and Three.js.

Explore the planets, travel through space, and experience the solar system from your own perspective.

This Simulation is a personal project designed to make exploring our solar system more interactive and accessible.

# Features

- **3D Solar System:** Explore the Sun and planets in an interactive 3D environment.
- **Planet Teleportation:** Select a planet label to travel directly to that planet.
- **Two Flying Modes:** Choose between Chill and Light Speed.
- **Cinematic Mode:** Switch to a more realistic lighting experience.
- **Interactive Camera:** Look around and zoom in or out while exploring.
- **Planet Labels:** Identify planets and view their displayed distances.
- **Cross-Device Experience:** Designed to work on desktop and mobile browsers.

The simulator is an ongoing personal project. Features, visuals, controls, and performance may continue to improve as development progresses.
